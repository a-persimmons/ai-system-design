# 成本优化 {#cost-optimization}

人工智能很昂贵。成本优化是一项日常活动。

降低成本的常用方法：

## 1. 尽可能使用更便宜的模型 {#1-use-a-cheaper-model-when-possible}

将简单查询路由到更便宜的模型（如 Haiku），并仅使用昂贵的模型（如 Opus）进行硬查询。

## 2.使用提示词缓存 {#2-use-prompt-caching}

对于长系统提示词，提示词缓存可将投入成本降低高达 90%。

## 3.使用语义缓存 {#3-use-semantic-cache}

对于重复的问题，语义缓存返回保存的答案，而根本不调用 LLM。

## 4. 较短的输出 {#4-shorter-outputs}

训练用户（使用提示词指令，例如“用 2 句话回答”）或硬限制 (`max_tokens`) 以保持输出简短。输出 token 通常比输入 token 贵 4 到 5 倍。

## 5. 自托管较小的模型 {#5-self-host-smaller-models}

对于大批量、低难度的任务（例如短文本的分类或摘要），可以在我们自己的 GPU 上自行托管一个小型模型。大规模固定 GPU 成本可能比每个 token API 成本更便宜。

## 6. 批量推理 {#6-batch-inference}

对于非紧急作业（例如过夜批处理），请使用批处理 API（OpenAI 批处理、Anthropic 批处理）。这些通常比实时 API 便宜 50%。

## 7. 更好的检索（针对 RAG） {#7-better-retrieval-for-rag}

好的 RAG 仅检索相关的文本块，因此 LLM 需要读取的内容较少。错误的 RAG 会转储太多上下文，速度缓慢且成本高昂。

我个人认为成本优化是一种习惯，而不是一次性任务。像观察延迟一样观察成本仪表板，并根据我们的用例应用这些杠杆。

成本优化是一项永无止境的工作。每个团队都有专人每天查看成本仪表板。
