# 什么是 AI 系统设计 {#what-is-ai-system-design}

**AI 系统设计是围绕人工智能模型设计完整系统的学科，特别是大语言模型 (LLM)，以便它能够以快速、廉价、可靠、安全和可测量的方式为真实用户服务。**

简单来说：

**AI 系统设计 = 系统设计 + AI模型的新约束.**

新的约束包括 GPU、token、长响应和流式响应、非确定性输出以及每个请求的实际成本。 AI 系统设计是我们设计缓存、队列、数据库、网关、检索、智能体、防护机制以及围绕这些约束进行评估的方式。

假设我们想要构建一个客户支持聊天机器人。在脚本中调用 LLM API 需要十行代码。但是，为 100,000 位用户提供的答案可以在不到一秒的时间内启动，以我们自己的文档为基础，永远不会泄露私人数据，并且符合每月预算 - 这就是 AI 系统设计。
