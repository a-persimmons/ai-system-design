# 为什么学习 AI 系统设计 {#why-study-ai-system-design}

当我们大多数人开始使用 AI 时，我们只需选择一个 OpenAI 或 Anthropic API 密钥，编写一个调用 API 的小脚本，然后获得响应。我们觉得我们的人工智能应用程序已经构建完成。

对于小型项目或个人演示来说，这已经足够了。

但现实世界却大不相同。

在现实世界中，人工智能产品服务于数百万用户。每个用户发送长提示词。每个响应均由 token 传输 token。模型很慢。 GPU 很昂贵。成本增加得很快。 幻觉悄悄出现。延迟很重要。

单个 API 调用无法处理所有这些。

为了让我们的人工智能产品可靠、快速、便宜和安全，我们必须共同考虑很多事情。这就是 **AI 系统设计** 发挥作用的地方。
