# 多租户 {#multi-tenancy}

大多数人工智能产品服务于多个客户。每个客户都有自己的数据、提示词和预算。这是 **多租户** 。

在多租户AI 系统中，我们需要：

- **每个租户的费率限制：** 客户 A 不能吃掉所有的 token。
- **每租户配额：** 客户 A 每月支付 X token。
- **每租户成本跟踪：** 我们知道为每个客户服务花费了多少费用。
- **每租户数据隔离：** 客户 A 的 RAG 文档永远不会返回给客户 B。
- **每租户提示词定制：** 客户 A 可以拥有可定制行为的定制系统提示词。

多租户在人工智能领域很难，因为一切都是共享的：GPU、推理服务器、缓存。我们必须小心，确保一个客户的数据不会泄漏到另一客户的响应中，尤其是通过缓存。

在这里，AI网关让我们的生活变得轻松。一旦每个 LLM 呼叫都流过网关，每个租户的限制、配额和隔离就成为单一配置，而不是分散在系统中的代码。
