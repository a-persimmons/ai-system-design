# AI 系统设计面试题 {#ai-system-design-interview-questions}

这些是最常见的 AI 系统设计面试问题。对于每一个，上面的 8 步框架都有效，并且提示告诉我们哪些构建块最重要。

- **根据公司文档设计客户支持聊天机器人。** RAG、混合搜索、重排序、提示词缓存、防护机制、升级到人员，并使用 LLM 评审进行评估。
- **设计 ChatGPT（大规模通用聊天助手）。** 推理服务器、预填充和解码、连续批处理、SSE 流式传输、模型路由、上下文窗口管理、内存和粗略 GPU 估计。
- **设计一个类似Perplexity的AI搜索引擎。** Web检索、混合搜索、重排序、答案中的引用、语义缓存和流式传输。
- **像Claude Code或Cursor一样设计AI编码智能体。** 智能体循环、工具调用、代码库RAG、沙箱、权限、子智能体、上下文压缩以及测试验证。
- **设计实时语音AI 智能体.** 流STT、LLM和TTS、延迟预算、转弯检测、打断、电话和工具调用。
- **设计一个多智能体研究助理。** Orchestrator和workers，子智能体，并行协调，共享内存，成本限制和跟踪。
- **为多个团队设计 LLM 推理平台。** vLLM 或 SGLang，使用预热资源池进行 GPU 自动扩缩容，通过出色的 token、前缀感知路由、预填充与解码分离和多租户进行负载均衡。
- **为公司设计 AI 网关。** 多提供商故障转移、token 的速率限制和成本、缓存、防护机制、审核日志和可观测性。
- **为长法律合同设计文档问答系统。** 文档解析、结构感知分块、无向量 RAG 或 GraphRAG 以及忠实度评估。
- **为 LLM 响应设计语义缓存。** 嵌入向量、向量搜索、相似性阈值、每租户隔离和失效。
- **设计设备端AI助手。** 小语言模型、量化、蒸馏以及混合设备端和云路由。
- **为 LLM 产品设计评估和监控管道。** 评估集、LLM 评审、智能体轨迹评估、跟踪和跨度以及成本和质量警报。

如需更多练习，请使用 [AI 工程面试问题和答案](https://github.com/amitshekhariitbhu/ai-engineering-interview-questions)。
