# AI 系统的扩展 {#scaling-ai-systems}

当流量增长时，我们需要扩展。

在常规系统设计中，扩展意味着更多的 CPU、更多的 RAM 或更多的机器。

在 AI 系统设计中，缩放具有更多风味，因为 LLM 很大。像 Llama 70B 这样的模型甚至不适合单个 GPU。我们需要将模型拆分到多个 GPU 上。

让我们看看不同的扩展方法。

## 垂直扩展 {#vertical-scaling}

使用更大的机器。在人工智能中，这意味着更大的 GPU。

示例：从 A100 (80 GB) 迁移到 H100（80 GB，但速度更快）或 H200 (141 GB)。

这仅在一定程度上有效。市场上最大的 GPU 仍然有限。大模型不适合。

## 水平扩展 {#horizontal-scaling}

添加更多 GPU 机器并在它们前面放置一个负载均衡器。

示例：我们有 4 台推理服务器，每台推理服务器在一台 A100 上运行 Llama 8B。负载均衡器在这些服务器之间分配用户请求。

这是最常见的缩放形式。当模型适合一个 GPU 时，它可以完美地工作。

## 张量并行 {#tensor-parallelism}

当模型不适合一个 GPU 时，我们会将模型本身拆分到多个 GPU 上。

示例：16 位精度的 Llama 70B 需要大约 140 GB。单个 A100 具有 80 GB。因此，我们将模型拆分为 2 个 A100。每个 GPU 持有一半的模型权重。当发生前向传递时，GPU 通过 **NVLink** （NVIDIA GPU 之间的高速直接连接，比通过常规网络快得多）相互通信以计算结果。

这称为 **张量并行** ，因为我们将模型的张量（权重矩阵）拆分到 GPU 上。

## 流水线并行 {#pipeline-parallelism}

在流水线并行中，我们将模型的不同层放在不同的GPU上。

示例：模型有 80 层。我们将第 1 至 40 层放在 GPU 1 上，将第 41 至 80 层放在 GPU 2 上。token 首先经过 GPU 1，然后到达 GPU 2。

这对于具有很多层的大型模型很有用。

这是两种并行样式的并排图片：

```
Tensor Parallelism                         Pipeline Parallelism
(split each layer across GPUs)             (split layers across GPUs)

         Input                                    Input
           |                                        |
           v                                        v
   +--------+--------+                         +---------+
   | GPU 1  | GPU 2  |  layer 1                |  GPU 1  |   layers 1..40
   | weight | weight |  (weights split)        +---------+
   | half A | half B |                              |
   +--------+--------+                              v
           |                                   +---------+
           v                                   |  GPU 2  |   layers 41..80
   +--------+--------+                         +---------+
   | GPU 1  | GPU 2  |  layer 2                     |
   |  ...   |  ...   |                              v
   +--------+--------+                            Output
           |
           v
        Output
```

在张量并行中，GPU 在每一层内相互通信。在流水线并行中，每个 GPU 在将 token 传递到下一个 GPU 之前完成其层。两者可以结合起来用于非常大的模型。

## 如何选择 {#how-to-choose}

我们根据模型大小和流量选择扩展策略：

- 小模型+低流量：1个GPU就够了。
- 小模型+高流量：使用负载均衡器进行水平扩展。
- 大模型+低流量：一台机器内的张量并行（多个GPU）。
- 大模型+高流量：模型张量并行+流量水平扩展。
