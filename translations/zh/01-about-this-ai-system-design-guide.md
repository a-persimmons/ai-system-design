# 关于本指南 {#about-this-ai-system-design-guide}

在本指南中，我们将了解 AI 系统设计，即将 GPU、推理服务器、缓存、向量数据库、AI 智能体、网关、防护机制和评估一起放入一个快速、廉价、可靠和安全的系统中的规则。我们还将了解 LLM 如何在 GPU 上实际运行、预填充和解码如何调整延迟、缓存、路由和批处理如何降低成本、RAG 和 AI 智能体如何构建用于生产、我们如何保持系统安全和可测量，以及在采访中解决任何 AI 系统设计问题的分步框架或者在实际生产中。

当我们使用 ChatGPT、Cursor、Perplexity 或 Claude Code 等产品时，我们会看到一个简单的聊天框和一个流式响应。在这个简单的界面背后，还发生了很多事情 - GPU、推理服务器、向量数据库、智能体循环、缓存、网关、防护机制以及一长串必须协同工作的设计决策。

本指南将我们所需的一切集于一处。我们从 token 和推理服务器等基础知识开始，通过硬件、预填充和解码、缩放、缓存、RAG、智能体驱动的系统、多智能体系统、多模态和语音系统、安全、可观测性、评估和推理优化以及完成一个分步框架来解决任何 AI 系统设计问题。

每个部分是：

- **为初学者编写。** 没有行话。没有假设。每个术语在使用之前都会进行解释。
- **注重实践。** 真实的数字、真实的权衡、真实的工具和真实的架构图。
- **连接到深入探讨。** 无论何时某个主题需要更深入，我们都会链接到一个详细的博客，从头开始对其进行解释。

本指南重点介绍 AI 的系统设计方面。要了解完整的人工智能工程路径 - 机器学习、深度学习、变形金刚、LLM、微调、RAG、AI 智能体等 - 请查看 [AI 工程课程](https://github.com/amitshekhariitbhu/ai-engineering-course)。
